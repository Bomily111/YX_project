# 测试工段支护按长度调度

14种已有支护模型的后方阵列现在支持1～20米整数名义长度，每米直接加载一个原始GLB单元，不拉伸、不重建构件。未给长度仍沿用测试示意默认10米；实际类型仍须明确选择。

## 参数链路

平台从受保护的用户原话解析长度，支持数字、常用中文整数和一米单元数量，忽略“一米单元/模板”本身的尺寸。小数、超范围、零/负数或多个长度不一致时，在准备新任务前拒绝，不自动取整或改成最近值。

长度通过 `AgentSceneWorkflowInput.supportLengthM` 进入只读预检与实际 `TaskContext.supportLengthM`。任务结构约束同步扩展，范围校验在替换已有场景前完成。逐阶段任务沿用该参数，资源实际加载数量、来源元数据、完成阶段输出、后端任务与快照均保留长度，最终工具反馈及左侧任务信息显示实际米数。

模型数组按所需数量建立，定位区间为[-length-0.5,-0.5]附近，继续给原模型锚杆伸出留间隔。原始截面、单元内构件间距及几何均不改。已有主隧道参考截面提取范围扩至源局部X=108～128，支持该测试范围的定位参考；这些是源坐标轴采样，不宣称是沿实测中线精确丈量的进尺。资源预算按最大长度保守估计200MB。

## 验证

56项相关长度解析、任务参数、源模型选择、工作流与相机测试通过，生产构建通过，既有包体积及Sass警告保留。

真实Edge在线调度连续验证：

1. 三台阶＋5米ZZ-Va，实际5份原始模型；
2. 同类型切换20米，实际20份原始模型，旧5份不残留；
3. 请求2.5米，拒绝且20米有效场景保留；
4. 请求21米，拒绝且有效场景保留；
5. 复位，全部任务模型引用释放。

左侧任务栏和完成反馈显示对应长度，后端快照的最终阶段长度及实际模型数量分别核对。详见[页面报告](verification/2026-11-11-support-length-final/report.json)、[20米截图](verification/2026-11-11-support-length-final/support-length-20.png)。上述5/20米真实页面验证采用ZZ-Va，其他类型通过共享参数链路接入，但没有据此宣称每种类型每个长度均已视觉验收。

仍是测试工段示意装配，曲线接缝、模板重复端盖、纵向构件连续性和各类型断面适配未做工程级重建。长度代表一米源模型数量对应的名义布置长度，不冒充设计进尺或工程量。
