# 通风增强资源级生命周期回归

日期：2026-10-12

## 验证对象

- CO 分析资源创建的实际 ECharts 覆盖层适配器
- 稳态 CFD 资源创建的实际 Cesium 剖切适配器
- 通风子资源与基础场景的卸载兜底

测试不替换通风资源适配器本身，只隔离 ECharts 渲染器、Cesium Viewer 外壳和通风模型加载等外部边界。

## 生命周期约束

每个适配器创建后会在所属资源下登记一个幂等清理句柄：

1. 增强引擎正常复位时，清理句柄立即注销并释放对象。
2. 子资源先卸载时，资源逆序执行仍登记的清理句柄。
3. 基础通风场景异常先卸载时，兜底清理全部剩余句柄。
4. 资源卸载后增强引擎再调用原撤销函数不会重复销毁对象。

## 自动化结果

连续 3 轮应用/卸载验证：

- `resize` 监听器：每轮从 0 增至 1，卸载后恢复 0。
- 覆盖层 DOM：每轮只创建 1 个，卸载后容器恢复空状态。
- ECharts：每轮执行一次 `dispose()`，重复撤销不会再次执行。
- `ClippingPlaneCollection`：卸载后恢复进入适配器前的集合，新集合进入 destroyed 状态。
- 通风增强租约：每轮卸载后恢复 0。
