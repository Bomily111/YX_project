# 围岩设计版切换爆破后的残留清理

用户反馈从围岩切到爆破时设计模型没有卸载。设计分级复用了公共隧道网格，不能通过销毁公共隧道解决，否则爆破也会丢失载体。

本轮修改：

- 主页面卸载时关闭设计分级，恢复隧道原始材质，清除分级标签与轮廓，退出全17段强制加载并恢复按距离加载。
- `setDesignRockGradeModelEnabled` 使用请求版本，离开页面后的旧异步启用请求不能覆盖新的关闭状态。
- 清除主页面800/1200毫秒的延迟初始化；内部等待重试和阶段异步回调在页面销毁后停止。
- 设计版全景/分段取景在等待资料后再次检查启用和Viewer状态，避免离开后继续改变新页面环境和相机。

真实页面脚本 `scripts/verify-rock-blast-cleanup.mjs` 覆盖正常切换、资料请求未完成时切换、延迟初始化前切换。检查同一Viewer、设计开关关闭、分级标签0、残留着色0、爆破模型ready以及无渲染错误，并保存截图。正常切换先等待至少一个实际分级着色模型就绪，防止只检查空场景。

证据：`docs/verification/2026-11-11-rock-blast-cleanup/report.json`；生产构建日志 `docs/verification/2026-11-11-rock-blast-cleanup-build.log`。失败复现保存在同前缀的 `-before` 目录，不作通过证据。保留已有未提交改动，5178验收服务重启后继续提供，未停止5173或3000。
