# 2026-11-11 连续支护共享边界

将连续支护从逐米刚性实例摆放改为逐单元几何拟合。每个顶点按模板纵向坐标，在起止断面的对应坐标间插值；相邻单元使用同一个边界矩阵，因此同坐标端部能衔接。保留原始模板与内部端盖删除规则，重新计算法线及包围体。任务快照新增 `sharedBoundaryFitting` 标记。

第一次真实页面测试暴露倾斜锚杆会伸出0至1米范围，已取消错误的范围拦截并用外推保留伸出部分，增加对应测试。失败记录保留在 `verification/2026-11-11-support-joints`。

最终真实页面验证YK2+244至YK2+264的20米ZZ-Va段：模型就绪，含20个单元，共享边界标记存在；复位后模型释放，页面错误为空。全流程约19.6秒，包含在线模型调度及资源加载，不能当作纯渲染耗时。记录见[复验报告](verification/2026-11-11-support-joints-final/report.json)，[截图](verification/2026-11-11-support-joints-final/continuous-support.png)。8项相关测试通过。

视觉检查确认整体仍有密集杆件和模板层次重复的问题，本次改善的是接缝坐标，不宣称外观已达到最终验收标准。人工弯曲与高程变化夹具验证端部一致，实际曲线段及坡度断面姿态仍待核查；原有断面朝向算法未改动。对离散构件也进行几何拟合属于示意，不能作为钢架或锚杆加工几何依据。掌子面几何载体仍未改造。

几何拟合不再使用刚性实例共享，内存估计改为每米12MB。20米页面已验证；30/50米在默认1400MB预算下可能连同1100MB主隧道被预检拒绝，不提高预算掩盖开销，后续需分离连续构件和离散构件来恢复实例化效率。
