# 支护纵向布置、参数与源依据联动

继续原开发总计划的支护样板，保留全部既有未提交改动。三台阶与支护异来源断面适用性未据本轮功能改为通过；本轮二维三维联动仅作为有明确数据边界的示意任务能力。

## 实现

- 1064米示例派生装配逐组记录实际用于放置的stationOffsetsM，独立单元回退记录实际unitOffsetsM。纵向图和只读支护报告共用同一行记录转换，不用构件数量反推站位，不从默认目录补造缺失记录。
- 新增可折叠的纵向布置图：按对象选择构件装配基准站位、查看本次长度、示例基准间距与站位数。工段设计要求和实测值均明确“未提供”。0m是测试源断面，不把局部相对坐标说成现场实测里程。
- 点击二维站位，按当前模型实际装配矩阵定位三维辅助标记并调整相机；点击三维定位标记，同步二维选中和文字记录。不移动或改造支护模型，不新建任务。三维标记是显示辅助，不能当作新增构件或构件中心的测量结果。
- Z-PM仅展示独立单元基准，间距字段“未核验”，明确这些基准不能推断配筋间距；不冒称1064米源示例的Z-PM布置。
- 来源区关联本次实际加载的GLB、捕获和元数据路径，以及源段编号。这里只提供源模型元数据依据，没有对应工段施工方案正文或页码，不冒充规范引用。
- 打开布置图才创建标记，关闭、换类型/长度或复位会移除标记和鼠标处理器；不在卸载时恢复旧相机，避免覆盖下一任务的新取景。清理自己选中的临时Entity，拒绝对已切换任务执行旧定位。

## 方法与数据边界

当前互选对象是装配基准的辅助定位标记，不是任意网格构件拾取；元数据来源可追溯，但尚无设计规范、施工方案正文的跨文档检索引用。不能据站位对齐宣称工程配准、构件实测间距或施工质量已核验。

后续仍需任务分析步骤组织、来源冲突与具体建议、支护内部结构的受控表达，以及其余场景质量和论文实验。二维图、取景和交互通过不代表整体基线或增强方法研究已经完成。
