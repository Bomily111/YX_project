# Z-PM加入全部可选模型目录

按用户“都是可选的”要求，Z-PM与原有13种ZZ单元一起开放选择，共14种。直接加载已有 `Z-PM_support_1m_partial.glb`，未修改源文件，也未补建缺失构件。

- 独立一米断面资源：`support.modeler-z-pm`。
- 测试工段后方10个一米单元资源：`support.test-section-z-pm`。
- 原ZZ-Va/Z-PM交替资源继续保留，不再是Z-PM唯一使用入口。

两种新入口均进入动态资源目录、智能体允许列表和页面名称。Z-PM已有构件只有二衬和N1～N7钢筋，界面、提示词和元数据均保留这个范围说明，不因资料不完整排除选择，也不冒称完整初支体系。

Z-PM源模型的设计标高点为y=0，而ZZ模板采用y=-2.1。独立和后方阵列分别按源标高点做刚性平移补偿，保持比例与几何不变。测试新增两类模型的设计标高点应落到相同参考标高的检查。类型匹配加入Z-PM并保留后缀精确匹配，不默认替用户选型。

30项相关测试、生产构建通过。真实Edge在线智能体验证Z-PM与三台阶组合、Z-PM单独断面、切换原ZZ-Va组合及复位；报告见[页面记录](verification/2026-11-11-zpm-final/report.json)，[Z-PM组合截图](verification/2026-11-11-zpm-final/three-bench-support-zpm.png)。几何仍为原始模板示意摆放，接缝和现场设计适配没有据此宣称完成。
