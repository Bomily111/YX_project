# R2 局部参照投影反馈阶段成果

## 范围与研究对应

对应开题R2的重点对象、必要空间参照、实际生效反馈（P0142、P0154、P0160及图2），并服务R3固定任务实验。本轮问题：局部组合使支护放大后，平台能否区别“重点与邻近参照投影保留”与“整个解释体入镜”，防止继续盲目拉近或声称地质信息已经足够。最小修改为现有几何参照与场景反馈的连接，不增加模型、工具数量或通用日志。验证两类既有任务、后方/不匹配域负例、真实在线读取与恢复；有限回归后停止。

## 已实现

从当前正交采样盒与实际支护包围球求最近采样参照，再沿盒轴在当前采样范围内生成有限探针；重复边界点合并。探针均在采样盒内，不表示有效体素、地质界面或可辨地质特征。非正交/退化参照不做错误投影，反馈不可用原因。

现有场景自检与视觉执行前后反馈增加supportContext，区分：支护保守包围球26点投影、局部采样探针投影、当前整个渲染采样盒的26点投影。判断仅为是否进入界面可用区域，始终保留informationSufficiency=not-verified、depthOcclusion=not-measured。局部投影条件满足时，建议停止仅为入镜而重复调相机；任务需要全段时仍回到整体范围。

页面视觉分析卡同步显示执行后局部探针入区数量及解释边界；任务切换、恢复仍沿现有流程。智能体实际读取后可据此说明局部与全段的取舍，而不能判断工程适用性或信息理解提升。

## 在线测试中纠正的问题

首轮在线测试中，模型在明确只读请求后没有重新查询，旧测试又仅检索“历史是否有inspect_task_scene审计”，错误地将它当作本轮读取。发现后在本记录中保留问题说明，修正测试为检查新增审计数量并拒绝“未取得本轮结果”的回答。

明确的当前场景只读请求现由平台先执行一次原有inspect_task_scene，将真实tool结果交给模型解释；模型仍负责解释与后续策略判断，视觉策略规划不变。这是用户明确只读请求的确定性读取，不宣称为模型自主选择查询。保留原无结果防护、非法修改拦截和引用校验；未注册工具时不强行调用。没有新增服务接口或工具。

最终在线模型解释了支护26/26、局部采样参照6/6、当前整个采样盒仅7/26入可用区，明确局部投影不能证明地质特征可辨、深度遮挡解决或验收。本次回答不再用历史查询冒充本轮状态。
