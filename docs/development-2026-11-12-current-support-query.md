# 查询当前支护装配结果

新增 `inspect_current_support` 只读工具及专用意图路由。支持“当前支护有哪些构件”“这段钢架间距多少”“当前哪些构件正在显示”等问题，从当前已完成任务的活动测试支护模型读取类型、实际长度、源文件、各组布置间距/站位及节点显隐；不沿用旧对话的类型和长度。

`getCurrentSupportReport` 核查实际模型就绪，按活动组聚合数据并给出中文名称。聊天结果由工具数据直接生成，明确站位数不等于杆件根数，示例参数不代表现场设计。Z-PM原模型回退没有分组时说明源示例为空范围，不猜测构件间距。无当前已完成任务或测试支护未加载时返回失败，不装配新场景。

查询使用当前taskId关联审计，并记录supportReport。现有显示/隐藏指令继续走set_support_layers，查询路由不拦截普通资源目录咨询或新建装配请求。本轮未增加长期记忆或历史恢复。

验证：`docs/verification/2026-11-12-support-query/report.json`，真实聊天串行装配Va、切换IVb、切换Z-PM、复位后查询共5项通过。Va/IVb先手动隐藏二衬再查询，核对回答读取最新节点状态与当前类型/长度/钢架间距，同时模型对象、任务数和显隐保持不变。16项相关测试通过，见 `2026-11-12-support-query-tests.log`；生产构建通过，见 `2026-11-12-support-query-build.log`。

范围：当前报告覆盖测试工段支护资源；未将独立断面资源或其他专题构件自动混入该报告。既有未提交改动保留，5178验收服务继续运行。
