# 开挖工段模型方向调整

用户提供同一系统的四张参考截图，强调开挖部分需要独立施工模型，例如三台阶开挖法。后续不能把“矩形照片改为轮廓裁切”当作主要模型成果。

## 从截图可观察的表达

整体场景沿施工轴线组织开挖面、支护、二衬和设备，并以里程标签标注工序位置。正面视角叠加炮孔，侧面视角呈现开挖实体及业务信息。截图不足以确认后台模型实现、精确台阶尺寸、错距或工程参数，不照抄其参数和配色。

## 下一步实现范围

先建参数化三台阶开挖示意工段：统一断面基准、上中下台阶高程、各台阶掌子面里程和未开挖岩体纵深；明确已开挖空间与剩余岩体，不以三张悬空照片或简单叠加三个方块代替。沿施工轴线表达上台阶超前、中下台阶错距跟进，按具体推进方向转换里程。支护应位于已开挖区，二衬位于后方，不能全部叠在同一里程。

几何生成与资料绑定分开：未提供现场工法参数时，只能进入明确标识的示意场景；任务实际装配须从用户信息或已有项目资料取得参数，不把演示值写成现场设计。任务未要求照片时不加载照片；需要照片时，只绑定对应台阶/断面，不将一张全断面照片任意复制到三个台阶，也不伪称单张照片恢复了岩体三维形状。

完成几何后再接智能体资源选择和任务数据。先验收侧面、正面和洞内近景，检查台阶体积、台阶之间的前后关系、支护位置和遮挡，再挂炮孔、监测、地质与设备信息。
