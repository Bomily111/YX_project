# 智能体按指定模拟时间装配近似热场

新增8个时间片资源，来自现有索引0/100/200/300/400/600/800/1000秒。每个资源独立持有数据，load确认索引对应时间与文件，activate实际生成温度点并通过增强适配器展示出口温度历程。主场景仅生成右洞3340点，专题默认双洞调用保持兼容。旧时间片卸载时仅移除自己持有的点集合，避免清掉刚激活的新集合。

提示词、资源白名单和中文标签已接入。温度场、热场、温度分布纳入普通任务识别；分钟转换成秒。在线模型曾把250秒自动映射到200秒，故增加AgentEngine输入预检及工具执行前时间一致性校验，不只依赖提示词。没有对应文件时先澄清，不取最近值。
