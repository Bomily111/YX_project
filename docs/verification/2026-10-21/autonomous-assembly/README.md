# 智能体自主装配阶段验收（2026-10-21）

## 验收目标

让智能体从自然语言任务选择资源顺序和逐阶段装配方式；平台在执行前校验同屏兼容性、资源预算和依赖。每步返回实际装配资源，支持观察结果后重算当前待执行阶段，任务快照可从 PostgreSQL 读回。

## 本轮实现

- 场景任务新增逐阶段 `assemblyModes`：`auto`、`retain`、`replace`。`retain` 保留上一阶段根资源并加入当前资源，`replace` 释放旧根资源后切换。首阶段及数组结构在准备时校验。
- 同屏白名单只开放现有示例资产中已核实布置关系的组合：设计围岩、DK278+330 的支护钢架和爆破效果；设计围岩与结构树既有支护的原示例布置。物探解释层互斥，异工点通风不能与 DK278 场景同屏保留。
- `revise_next_scene_assembly` 允许智能体在前一步完成后，针对当前待执行阶段重算装配方式。非法修改不替换原计划；资源切换仍由 `ScenePlanExecutor` 事务执行并支持复位。
- 工具状态返回每阶段根资源和上一阶段实际 `assembledResourceIds`。准备、步骤完成和计划修订快照保存装配选择及计划根资源；实际场景计划、增强计划和活动资产版本随步骤保存。

## 自动化验证

- 全量前端测试：25 个测试文件、144 个用例通过。
- 生产构建通过，资产清单 57 项校验通过；后端任务审计路由语法检查通过。
- 用例覆盖：围岩→支护→爆破逐阶段保留并同屏装配；显式切换；跨工点同屏拒绝；观察首阶段后重算下一阶段；非法修订保留原计划；复位后任务资源引用归零。
- 已执行 `npm run db:task-audit`，现有数据库支持 `plan-revised` 快照事件。
