# 施工任务语言的场景装配验证

“在某里程展示某模型”是点名资源的连通性用例，只能检验调用和加载，不能代表智能体理解施工任务。后续日常示例和论文评价应以施工目标、工点和需要观察的信息为输入，由智能体选择最少的现有场景资源；场景构建完成后再开展独立的增强可视化研究。

| 施工任务输入 | 期望的装配决策 |
|---|---|
| YK1+346 即将进行初期支护施工交底，请把岩体坚硬程度和现有支护布置放到同一场景查看。 | TSP 坚硬度与结构树既有支护组合 |
| YK2+244 掌子面超前地质预报交底，需要查看前方岩体完整性变化。 | TSP 完整度 |
| YK2+244 掌子面疑似富水，调出前方电阻率异常分布供施工研判。 | TEM 视电阻率 |
| 在 YK2+244 做掌子面施工风险研判，请把相关模型调出来。 | 信息类型不明确，先追问关注的风险或数据，不擅自加载模型 |

系统提示词现要求先识别施工任务需要观察的工程信息，再映射资源；“查看、调出、放到场景”可进入单次受控装配入口，质量检查、只规划和分阶段试验仍走各自路径。上述前三例与模糊例均通过 DeepSeek 在线工具选择测试。第一例又在真实浏览器完成一次任务：左侧显示 YK1+346、TSP 坚硬度和结构树支护组合；数据库回读 `completed 2/2`、九项资源加载，源 JSON、体纹理与支护 GLB 资产路径均已保存。

这些模型当前允许按 YK 中线示意重定位，仅用于验证任务理解和场景装配；不能把异工点示例数据当作 YK1+346 的实测结论。当前增强仍在装配阶段自动应用，尚未达到“完整场景构建后再增强”的目标流程。
