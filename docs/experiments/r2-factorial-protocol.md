# 支护重点与剖切的固定相机消融规程

本轮对应开题增强视觉变量选择与试验消融（P0154—P0155、P0160），服务案例实验准备。问题：在已经固定局部相机后，重点着色与近端展示剖切分别带来什么画面变化？初始最小改动限于实验脚本、结果及版本归档，不添加产品策略。复现中确认显式full仍沿用裁剪的语义问题后，范围补充为修复既有完整参照策略，并做单元和真实在线回归。两类既有任务各执行一次四条件对照，身份/变换或恢复错误即停止，不能用重复测试代替方法研究。

任务：坚硬度YK1+346与完整度YK2+244，各同屏support.modeler-zz-va。1400×900、Edge D3D11、同一Viewer。在已有near-support相机位置固定后，改变且仅改变两个因素：

| 条件 | 展示范围 | 支护重点显示 |
|---|---|---|
| full-plain | 原完整范围 | 原表达 |
| full-focus | 原完整范围 | 暖色混合 |
| cut-plain | 近端观察窗口 | 原表达 |
| cut-focus | 近端观察窗口 | 暖色混合 |

四条件用于同资产、同相机的工程预实验，不是开题三组人员实验，也不用于推断统计显著性。顺序固定，人员实验需另行平衡顺序。源体素、色标、源几何、支护对象/矩阵与目标里程不变；记录实际裁剪、颜色及混合参数，保持相机位置1微米/方向1e-12的数值比较容差。该容差只是浮点检查，不是视觉效果阈值。

使用已有算子直接设置四个条件，不通过重新装配或重置视觉调整预算进行切换；这是实验控制路径，不代表实际智能体可绕过每场景两次调整限制。每条件等待渲染并截图，之后恢复进入消融前的显示状态，再验证整个分析前状态及最终复位。

记录两因素取舍：重点轮廓与背景的区分、体渲染覆盖是否仍在、局部/全段参照变化。仅对截图做定性观察，不填造遮挡率、可见像素、构件正确率或信息理解提升。保存完整页面和固定中心区域两套截图，后者便于排除侧栏文字变化。关联实际完成任务资产快照。
