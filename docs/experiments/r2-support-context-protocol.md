# 围岩与支护策略对照预实验

本轮对应开题R2（P0142、P0154、P0160）及R3试验准备（P0155）。问题是局部参照组合相对全范围和仅支护近景的画面取舍。最小变更限于可复用页面对照脚本与任务规程；先看结果，不为增加功能而改策略。三个条件均使用同一已装配任务、同一资产与显示来源，检查支护对象及变换不变、恢复及退出正确。

这是策略层面的工程预实验，不是论文“人工操作/自主装配/装配并增强”三组人员实验；不测人员正确率或理解提升。

## 固定任务与问题

- 坚硬度：YK1+346，rock.tsp-hardness + support.modeler-zz-va。
- 完整度：YK2+244，rock.tsp-integrity + support.modeler-zz-va。
- 问题：支护轮廓是否可观察？附近解释体是否作为参照保留？完整解释体有哪些部分出画？哪些判断仍缺资料或几何测量？
- 1400×900画布，Edge D3D11、同一Cesium Viewer；仅源显示范围和策略规定的视角变化，源色标、支护对象/变换、里程与任务不变。

## 三个条件

1. 完整范围与整体视角：恢复源显示范围，保留进入比较时相机，作为无局部裁剪对照。
2. 仅支护近景：完整范围不变，仅切换已有支护视角；用于观察单独相机调整的作用及遮挡代价。
3. 支护与邻近围岩组合：从同一原范围及相机出发，使用已实现的near-support组合；明确全段不保证入镜。

截图顺序固定，用于工程检查，不用于人员统计；人员实验需要另行平衡顺序与学习效应。对每任务只执行一次完整对照，失败保留现场并说明，不无限重试。比较结束恢复源范围、相机及视角选择，最后复位释放。

## 记录与结论界限

保存每个条件完整页面截图、实际范围和相机、支护矩阵与对象身份。保存包围球投影近似尺度仅供取景诊断，不当作可见像素或辨识正确率。统一人工查看截图中的参照缺失、遮挡和图例，不给未经测量的可见率。

本轮停止条件：两类任务均完成三个条件、身份/几何保持、组合恢复与复位验证；或遇到真实失败后记录原因。若场景效果无改善，如实记录，不能靠选择性截图判为有效。模型源断面适用性、TSP源200m/登记100m、实测与设计正文问题保留。
