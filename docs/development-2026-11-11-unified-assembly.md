# 1064米支护示例与统一场景交互

本轮对应三个要求：按支护模块1064米示例布置支护、任务共用平台场景、复用通风/支护鼠标交互。保留工作区既有未提交改动。

## 支护来源和布置

`scripts/capture-support-1064-example.mjs` 从已有1064米页面导出实际构件，包括该页面动态加载的格栅和超前支护。文件保存在 `public/support-modeler/outputs/centerline/task-reference-1064.glb`，附来源和默认显隐记录。没有重新建支护构件。

`example-layout.ts` 读取对应类型的首个有效区段，复用原几何、材质、构件相对位置，并按各构件自己的示例间距沿测试工段中线法向布置。ZZ-Va钢架0.8米、ZZ-IVb钢架1米；20米ZZ-Va为25榀钢架，不再重复20个包含全部构件的1米包。钢筋、锚杆等保留在资产内，默认显隐沿用示例。生成装配文件只重排已有构件实例，并记录源文件和生成版本指纹。

示例缺少的构件不会补造。1064米中的Z-PM为空范围，仍使用已有Z-PM独立模型按原1米单元布置，元数据明确记录回退；不能将其称为已验证的1064米Z-PM布置。现有部分类型源模型本身为局部模型，保留该状态。

## 统一场景

`TaskScenePresentation.ts` 不再为任务改黑背景或关闭地球、天空、太阳、月亮和雾。三台阶和支护使用主Viewer，仅调整模型强调和相机取景。任务装配回归脚本检查画布对象相同、只有一个Cesium画布、背景和环境状态前后一致。

## 交互

`PlatformModelControls.ts` 复用现有通风/支护控制器：左键围绕拾取点旋转，右键/中键/Shift左键平移，滚轮向指针处缩放，双击聚焦。主界面、围岩、调度共用主画布；爆破接入同一适配器。移除旧导航监听，卸载时释放输入/帧监听并恢复状态。

修正指针缩放后平移会重定向视线的问题；相机自动飞行结束会由Cesium重新启用默认输入，因此适配器在帧更新和输入捕获阶段保持自定义控制权，防止叠加。

真实页面另发现Cesium透明深度拾取会重跑已完成的一次性计算指令，抛出 `VertexArray ... object was destroyed` 并停止渲染。平台适配器使用已完成的非透明深度缓冲，自动取中心也不在相机moveEnd帧内做GPU拾取。保留显式鼠标拾取与观察平面回退。
