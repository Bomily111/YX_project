## 6. 下一步优先处理的具体问题

1. **继续完成空间验收。**主页面隧道按分段 GLB 放置，风场按中线中心和断面范围映射，支护以自己的设计基准点定位。统一检查断面底板、中心、拱顶和轴向，不能仅比较包围球中心。当前截图仍有密集点、矢量穿插及点贴在外壳表面的观感。
2. `cesiumVentilation.ts` 的点、箭头端点、粒子使用 `disableDepthTestDistance=Infinity`，所以即使在洞内也会绘在外壳前；这是显示机制，不能仅靠截图把它判为真实裸露。后续结合受控透明/剖切做遮挡验收。
3. **爆破重复任务生命周期。**目前重定位只在资源 `load` 执行，`activate` 仅显示，缺少按新 task 重新定位的 `update/resetTaskPlacement`。资源未卸载时从 4000 切到其他里程，或回到原 1346，可能保持旧变换。应补含原位恢复的受控 placement 生命周期和回归。
4. 爆破方向常量由当前点云拟合，试验通过的是该定义轴与目标 tangent；仍要用独立几何控制点验证，不应只用同一常量自证精度。包围球定位中心也应替换为明确断面控制点。
5. 通风组合模式为全局开关，`ventilationPositionToLocal` 仍用原专题矩阵逆变换。当前组合 steady 路径不使用该逆函数，但跨页面/多 Viewer 交互需要审计。
6. 组合通风 `ventilation.scene` 不加载 GLB，`getEnhanceTargets` 返回的空对象目标、steady 依赖只有 `ventilation.scene` 而非明确公共隧道，以及镜头/左右栏布局，都需结合实际任务验证。不要把主页面原来已有公共隧道作为资源依赖正确性的唯一依据。
7. 同屏来源说明目前常取最后阶段 note，可能遗漏较早阶段的爆破示意来源；尤其爆破放在风场前后两种顺序都要验证。小于 1346 的爆破重定位来源提示条件也需补齐（当前 note 只检查 `>1351`）。
8. 任务图层释放、重试、重复同里程任务、失败回滚、专题页切换和数据库实际资产一致性都需要在上述生命周期修正后复验。
