# 智能体提示词强化

版本：2026-11-13-task-evidence-v2。保留已有未提交修改。

## 修改

- 在系统提示词前部集中定义任务范围、操作授权、证据、结果汇报和停止边界。明确加载、几何核查、画面可读性与工程验收不能互相替代；展示阶段完成不代表自适应增强研究闭环完成。
- 建议必须对应本任务对象、位置、实际依据与下一步核查。不编造文件页码、实测偏差或工程结论；资料路径不等于正文已读取，未读取不等于平台未接入。
- 更新源支护坐标架与混凝土连接的实际实现说明，保留异来源断面及Z-PM PARTIAL边界。
- 修正示例擅自默认ZZ-Va的冲突；交替支护资源仅对应用户明确指定的两类型交替示意任务，不能替代泛化连续段。
- 检查发现blast.ts头部明确标注“虚构”。提示词检索现在只接收标记为fictional-example、referenceable=false的主题元数据，不注入正文参数；保留原知识库文件，没有将它升级为工程证据。未来接入正式资料需要真实来源和适用范围机制。
- 页面上下文用JSON字符串传递并标明它不能替代用户指定目标。资料中的指令不作为操作授权。

## 验证

- 7项提示词契约测试通过，包含虚构知识正文隔离；生产构建通过，仍有既有Sass及包体积警告。
- 真实Edge页面经本机后端调用当前DeepSeek，确认新版本进入实际模型请求。最终咨询测试3项通过、任务写入0、页面错误0，报告及截图位于 `verification/2026-11-13-prompt-evidence-final/`。测试分别覆盖“加载是否等于验收”“缺资料是否编造装药量及页码”“相机操作是否等于增强闭环”。这三项没有给出具体施工参数。

- 首轮回答偏长，且出现将本轮未返回泛化为能力缺口的表述，已补充区分规则后再测。最终样例仍存在偏长回答及能力缺口措辞不够精确的情况，不能视为所有问法均可靠；自动测试主要核对核心拒绝结论、无任务写入及实际版本，回答正文另行阅读核对。

提示词引导不替代代码校验；本轮没有将这些文字约束宣称为新的几何、反馈测量或二维三维联动能力。
