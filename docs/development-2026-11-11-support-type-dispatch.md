# 13种已有支护单元按任务选择

三台阶后方支护不再固定ZZ-Va。测试工段资源目录直接复用 `modelerSupportCatalog` 的13种类型及原始路径：ZZ-II、ZZ-III、ZZ-IIIx、ZZ-IVa、ZZ-IVb、ZZ-IVc、ZZ-IVsx、ZZ-IVx、ZZ-QJsx、ZZ-S、ZZ-Vsx、ZZ-Y1、ZZ-Va。

## 行为

每种类型对应一个测试支护资源。为兼容已有记录，ZZ-Va仍使用 `support.test-section`；其他类型为 `support.test-section-` 加小写类型，例如 `support.test-section-zz-ivb`。这13项均已注册到任务目录和智能体允许资源中，可独立展示或与三台阶组合。

每项直接加载所选原始GLB的10个1米单元，仅作刚性定位，不重新生成、变形、缩放或替换构件。原模型组成各不相同，来源元数据记录实际supportType和source路径，不把所有类型都称作包含二衬或钢架的完整体系。测试位置仍为YK2+244，后方10米为示意布置，不代表现场类型选择或断面适配结论。

每个类型独立持有模型数组；相机、整体/支护视角、来源说明和任务快照按实际选择取值。切换类型时旧资源释放，不将多个类型叠在同一支护段。一次测试任务只允许一种后方支护类型。

执行前校验用户明确指定的类型与资源一致；缺少类型、类型不符或多类型歧义时，在准备/替换场景前拦截，不默认退回ZZ-Va。支持III/IIIx、IV/IVsx等后缀精确识别。测试工段缺类型时先澄清，补充类型后保留原始三台阶任务及测试工段约定，不强迫重说任务。当前未接入可替代用户明确选择的工法设计记录，不能从围岩等级自行认定支护类型。
