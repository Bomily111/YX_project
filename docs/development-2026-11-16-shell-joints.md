# 生成支护外壳端部连续性诊断

保留全部既有未提交修改，接续场景基线验收。本轮未改变源轮廓、支护尺寸或三台阶几何。

## 修正验收盲区

原真实页面几何检查对1064米示例派生的外壳返回空的接缝指标，不能据其通过宣称外壳接缝已测。本轮从实际生成几何读取相邻单元的首末端顶点，计算双向最近顶点距离，记录构件、接缝数、有效计算数及最大值。诊断随当前支护工具报告返回，并在源断面面板展示。

该数值是离散顶点集合距离，不是连续表面间隙、断面贴合、三台阶交界或现场测量。独立Z-PM尚未接入此项诊断，工具保留null，不补成零。不将此诊断视为工程验收通过。

实现中发现Three BufferGeometry.clone共享userData，已显式隔离派生几何的诊断数据，并在导出前清除临时顶点数组；不污染缓存源资产，不增加导出资产中的诊断数组。

## 验证

- 11项测试通过，实际读取13种源支护的初支与二衬，验证端部顶点连续、内部端盖移除及源数据隔离；补充不对称样本与无效样本检查。
- 真实Edge D3D11七流程通过：Va、IVb、Z-PM的5米与20米及复位。包含俯视、侧面、近景截图。Va/IVb在源核对面板显示有效接缝计算数和最大距离；Z-PM沿用独立单元原有检查，不能混称此项已测。
- 最终记录：`verification/2026-11-16-shell-joints-final/report.json`。早期两目录为热更新导致动态导入与页面单例分裂的失败记录；核对归属后只重启5178验收Vite，未停止5173及3000，重新浏览器验证通过。
- 生产构建通过，保留既有Sass及包体积警告。

页面仍明确源轮廓差异：测试隧道断面宽约11m，Va初支源宽约12.72m、二衬约12m。没有设计适用性资料，不能擅自缩放源支护消除差异。下一步仍需处理源断面适用性、实际三台阶交界及全场景视觉质量台账；本轮只补足外壳自身连续性的可追溯诊断。
