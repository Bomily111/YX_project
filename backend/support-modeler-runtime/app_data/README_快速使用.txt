隧道支护参数化建模 V1.3 阶段交付版

【启动】
双击“启动_V1.3.bat”。资源检查通过后会自动打开统一导航页，服务运行期间请保留命令窗口；关闭窗口即可停止服务。
电脑需要安装 Python 3.10 或更高版本，安装时勾选“Add Python to PATH”。首次使用真实图纸识别前，请联网双击“安装_V1.3依赖.bat”安装识别依赖；依赖安装完成后，日常建模和识别无需联网。
默认地址为 http://127.0.0.1:8000/index.html；若端口被占用，窗口会显示实际端口。

【加密 PDF】
密码不会保存在交付包中。请在启动前设置 Windows 环境变量 SUPPORT_PDF_PASSWORD，或在当前 PowerShell 窗口执行：
$env:SUPPORT_PDF_PASSWORD="您本地持有的密码"
再从同一环境启动。密码错误或未配置时，页面会显示明确提示。

【图纸识别状态】
REAL_OCR_RUN 表示本次确实执行了识别；REAL_OCR_CACHE 表示相同文件命中了此前真实识别缓存。两者不会混用。

【单断面 Demo】
用于选择支护类型、查看构件、调整自身几何参数和纵向布设参数、显示数学辅助线与空间检查、保存 Variant，并导出单断面 GLB。

【真实 1064m Demo】
用于查看 YK1+098～YK2+162 的23个真实区段。选择区段后，只会列出与该支护类型匹配的 Variant；应用和恢复仅影响当前区段。可导出包含方案记录的整段 GLB。

【推荐操作】
先在单断面页面选择支护类型并保存 Variant，再点击“返回整段隧道”，选择同类型区段并应用方案。

【当前边界】
ZZ-Va钢筋网与钢架连接节点、锁脚部分安装参数，以及ZZ-IIIx纵向连接筋端部R55弯折平面仍待工程确认。ZZ-IIIx初支钢筋网和系统锚杆尚未完整实现。页面保留CONFIRMED、PROVISIONAL、PARTIAL、NEEDS_CONFIRMATION等真实状态。
