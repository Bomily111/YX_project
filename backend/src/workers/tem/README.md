# 瞬变电磁（TEM）处理管线 — run_tem.py

## 概述

隧道瞬变电磁法超前地质预报数据的完整处理管线。输入 4 条测线的 `.dat` 原始数据，经 RBF 扇面插值、三维 IDW 体素建模、异常体检测，输出体渲染数据、三维模型、可视化图片。

**数据采集几何**：4 条测线共享掌子面中心原点，每条测线在各自的扫描断面内以扇形扫描 9 个方向（-60° ~ +60°，间隔 15°），探测距离 0~60m。

---

## 用法

```bash
python run_tem.py --input <dat_dir> --job-id <uuid> --output <public_dir>
```

| 参数 | 说明 |
|------|------|
| `--input` | 包含 `线1.dat` ~ `线4.dat` 的目录（文件名需含数字 1~4） |
| `--job-id` | 任务唯一标识，作为输出子目录名 |
| `--output` | 平台 public 数据目录（如 `public/data/tem_output`） |

## 进度协议

脚本通过 stdout 输出进度，供 Node.js 后端解析：

| 格式 | 说明 |
|------|------|
| `LOG:<消息>` | 日志行 |
| `PROGRESS:<0-100>` | 进度百分比 |
| `COMPLETE` | 处理成功 |
| `ERROR:<消息>` | 处理失败，脚本 exit(1) |

---

## 处理流程

```
线1~4.dat (360点/线, 共1440采样点)
  │
  ├─ Step 1: 2D RBF 扇面插值 (thin-plate-spline, 250×250网格)
  │    每条线独立处理 → ~53k 密集点/扇面
  │
  ├─ Step 2: 扇面 → 三维坐标映射
  │    u = d·cosθ (前向), v = d·sinθ (横向)
  │    x = u·cosφ, y = v, z = u·sinφ
  │    4 扇面共 ~212k 三维点
  │
  ├─ Step 3: 三维体素 IDW 插值 (80×100×80 = 640k 体素)
  │    逐扇面均衡 IDW + 3D 高斯平滑
  │
  ├─ Step 4: k≈570 等值面异常体检测
  │    连通区域标记 → 异常体统计
  │
  └─ Step 5: 输出生成
```

## 坐标系统

- **X 轴**：掌子面前方（掘进方向），范围约 0~60m
- **Y 轴**：横向（隧道宽度方向），范围约 ±60m
- **Z 轴**：垂向（高程方向），正值为向上
- **原点 (0,0,0)**：掌子面中心

## k 值含义

- **低 k 值**（<570）：疑似富水区、破碎带、溶洞等低阻异常体
- **正常 k 值**（570~640）：完整岩体背景
- **高 k 值**（>640）：高阻完整岩体

## 扫描几何

| 测线 | 倾角 φ | 说明 |
|------|--------|------|
| 线1 | +30° | 斜向上顶拱方向 |
| 线2 | +15° | 斜向上 |
| 线3 | 0° | 水平方向 |
| 线4 | -15° | 斜向下底板方向 |

每条线扫描 9 个方向：θ = -60°, -45°, -30°, -15°, 0°, 15°, 30°, 45°, 60°
